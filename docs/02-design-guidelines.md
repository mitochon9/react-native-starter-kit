# デザインガイドライン

## 1. デザインコンセプト

### 方向性

**Vercel / Resend 寄りのミニマルデザイン**

- クリーンで余白を活かしたレイアウト
- 情報が整理されて見える
- 「プロが教える」信頼感
- 冷たすぎず、適度な温かみ

| サイト | 参照ポイント |
|--------|-------------|
| [Vercel Blog](https://vercel.com/blog) | 全体のトーン、余白の使い方 |
| [Resend](https://resend.com) | 温かみのあるミニマル |
| [Tailwind Blog](https://tailwindcss.com/blog) | 記事の可読性 |

## 2. カラーパレット

### ライトモード（基調）

| 用途 | カラー | 備考 |
|------|--------|------|
| Background | `#FFFFFF` / `gray-50` | 純白 or わずかにグレー |
| Foreground | `#171717` / `neutral-900` | ほぼ黒 |
| Muted | `#737373` / `neutral-500` | サブテキスト |
| Border | `#E5E5E5` / `neutral-200` | 控えめな境界線 |
| Accent | TBD | ブランドカラー（後で決定） |

### ダークモード

| 用途 | カラー | 備考 |

| Foreground | `#FAFAFA` / `neutral-50` | ほぼ白 |
| Muted | `#A3A3A3` / `neutral-400` | サブテキスト |
| Border | `#262626` / `neutral-800` | 控えめな境界線 |

## 3. タイポグラフィ

### フォントファミリー

| 用途 | フォント | 備考 |
|------|----------|------|
| **見出し** | Geist / Inter | シャープ、モダン |
| **本文** | Inter | 可読性高い |
| **コード** | Geist Mono / JetBrains Mono | 開発者向け |

### フォントサイズ（Tailwind）

| 用途 | サイズ | クラス |
|------|--------|--------|
| H1 | 48px / 3rem | `text-5xl` |
| H2 | 30px / 1.875rem | `text-3xl` |
| H3 | 24px / 1.5rem | `text-2xl` |
| Body | 16px / 1rem | `text-base` |
| Small | 14px / 0.875rem | `text-sm` |

### 行間

- 見出し: `leading-tight` (1.25)
- 本文: `leading-relaxed` (1.625)

---

## 4. スペーシング

### 基本原則

- **余白を惜しまない**：情報密度を下げる
- **一貫性**：8pxグリッドベース
- **セクション間**：`py-16` (64px) 以上

### コンテンツ幅

| 用途 | 幅 | クラス |
|------|-----|--------|
| 記事本文 | 680px | `max-w-2xl` |
| 通常コンテンツ | 1024px | `max-w-4xl` |
| ワイドコンテンツ | 1280px | `max-w-6xl` |

## 5. コンポーネント

### UIライブラリ
